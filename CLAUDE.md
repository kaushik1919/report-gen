# AI Academic Report Generator

## Mission
Build a local-first MVP for AI-generated university reports.

## Core Principle
1. Extract formatting deterministically
2. Generate semantic content separately
3. Render programmatically

## Stack
- Python
- FastAPI
- Streamlit
- Ollama
- python-docx
- docxtpl
- ChromaDB

## Development Rules
- Keep architecture simple
- Avoid overengineering
- Commit frequently
- Push to GitHub after milestones
- Keep code modular
- Prefer DOCX-first architecture
- Use local models first
- Avoid cloud costs initially

## Current Goal
Build Phase 1 MVP:
- template upload
- style extraction
- section generation
- DOCX export

## Coding Standards
- Type hints where useful
- Clear folder structure
- Avoid giant files
- Production-minded code
